# Changelog

## 0.1.0 — 2026-10-02

Initial public release of Face Detection Lab.

- Detects frontal faces in trusted local images using OpenCV's bundled Haar cascade.
- Supports local image annotation and optional pixelation.
- Writes JSON face-coordinate reports without overwriting existing outputs.
- Includes live webcam preview without recording frames.
- Preserves source images and keeps detection separate from recognition.
- Includes automated tests, a licensed sample, documentation, and GitHub Actions coverage.
